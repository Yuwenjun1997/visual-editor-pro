# 产品需求文档

状态：Confirmed（首发核心范围）

## 目标

将现有低代码页面搭建与内容后台升级为可对外发布的单租户 SaaS。用户可以维护内容、搭建页面、保存草稿、发布线上版本，并通过固定站点 URL 分享页面。

## 首发范围

- 页面草稿、发布、版本和回滚。
- 固定站点 `/p/:slug` 匿名访问已发布页面。
- 商品、文章、分类和数据源管理。
- admin/editor/viewer 三种角色。
- Supabase RLS、公开 RPC、Storage 安全策略。

## 暂不包含

组织协作、计费、自定义域名、审批流、插件市场和复杂 CMS 工作流。

## 发布验收

草稿不可匿名访问；发布后可通过唯一 slug 访问；修改草稿不影响线上版本；回滚后线上内容恢复；跨用户访问和停用数据源均被拒绝。
